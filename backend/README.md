# Re:Code Backend Service

Backend service for **{ Re:Code }** (Read. Review. Refine.), powering:
- AST parsing and static deterministic security analysis (OWASP, syntax validation, rule sets).
- Google Gemini 1.5 Pro integration for context-aware code diagnostics and 1-click patch generation.
- Supabase integration for audit history, user sessions, and compliance metrics.
- Rate-limiting safeguards and GitHub repository inspection pipeline.

## Scripts
- `npm run dev` - Start local backend development server
- `npm run start` - Start backend production server
- `npm run test` - Execute backend test suite
